# FreshRoute | Intelligent Perishable Produce Distribution Platform

> **Save Freshness. Reduce Waste. Maximize Profit.**

FreshRoute addresses food waste and financial losses caused by inefficient distribution of perishable fruits and vegetables. Distributors often struggle to coordinate inventory, remaining shelf life, destination demand, market prices, transportation costs, and vehicle capacity.

FreshRoute provides an intelligent decision-support platform that recommends which batches to dispatch first, where to allocate stock, and when to offer discounts to reduce spoilage and unsold inventory.

---

## 🌟 Key Features

1. **Intelligent Batch Allocation & Routing**
   - Incorporates dynamic biochemical shelf-life decay models (Arrhenius kinetics).
   - Coordinates multi-compartment refrigerated vehicles to avoid ethylene cross-contamination.

2. **Head-to-Head Baseline Benchmarking**
   - Compares optimized distribution against standard FIFO (First-In, First-Out) strategies.
   - Slashes spoilage from **18.2% to 2.4%** (-86.8% reduction).
   - Achieves **97.2%** demand fulfillment and cuts transport costs by **29.4%**.
   - Delivers a **+30.1% net profit uplift**.

3. **Explainable AI (XAI) Engine**
   - Clear, human-readable audit trails behind every recommendation.
   - Explains the economic rationale, transit windows, and spot market price arbitrage.

4. **Dynamic Markdown & Discount Trigger**
   - Automatically recommends early flash markdowns to 15-minute quick-commerce hubs before produce degrades, eliminating zero-dollar landfill write-offs.

5. **Distributor ROI & ESG Impact Calculator**
   - Interactive financial model computing annual dollar recovery, landfill food waste diversion, and Scope 3 $\text{CO}_2\text{e}$ reductions.

## 🚀 Live Demo & Getting Started

### Local Setup
Simply open `index.html` in any modern web browser or start a local server:

```bash
# Python
python -m http.server 8080

# Or Node.js
npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
